Fruit Squash

Want to squash some fruit to your heart's content?
Well, now you can with Fruit Squash. Squish, Squash, Squelch, when you have enough fruit go ahead and head to the Market and purchase yourself some fruit squashers to continue gaining fruit without needing to use your fingers!

You can even squash your way into the Wheel of Fortune to gain yourself some free squashes ranging from 5 all the way up to 1000. Each activation of the Wheel of Fortune will add 500 to the number of squashes required to enter.

Fruit Squash is a mobile clicker game created in Unreal Engine 5.

The game has been created soley in Unreal Engine Blueprints, and has been optimised for both iOS and Android screen resolutions. Being created by myself and QA’d by friends and family, I have been able to deply beta versions of the application on both the Google Play Store and TestFlight so that I can get the game functioning for a full release.

I have used Jira as task management for the games progression, including logging bugs and imrpovenets as they have been requested from beta feedback I have collected. This feedback is still being taken into consideration so that I can improve the user experience with each update to the game.

Fruit Squash is designed to be fun and enjoyable for all ages.
