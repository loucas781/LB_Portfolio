F1 2017

While working at Codemasters in 2017 as part of some volluntary work experience I was part of the QA team working on their mainline title F1 2017.

During my time on the QA team I was responsible for playtesting through the Campaign, Multiplayer and solo aspects of the game through its development while under an NDA.

I was play testing the game on multiple different platforms, including PS4, Xbox One, and PC. During these tests I would follow reports submitted by private testers. These steps followed would confirm if the issue exists and if so which version of the game this would be occuring on. I would also be working on finding my own bugs within the game environment, and reporting these in a similar mannor if they could be replicated multiple times within the game.

I had competed in multiplayer test environments, testing the multiplayer sessions out on local test environemnts along with LAN sessions with the rest of the Codemasters development team. These would take place on a weekly basis to see if there was any major issues that would occur during this time.

All aspects of the game was tested and worked on, including Singleplayer Campaign, Solo Race, and Multiplayer all to make sure they was up to a professional standard with the least possible issues in time for release.

In order to make sure the issues reported and found was looked at in a professional mannor I used Codemasters insite bug managing ticket system to log all issues in a professional mannor, making sure to include all steps on replication, and provide a priority on the majority of the issue.
