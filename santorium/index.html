Santorium

Santorium is a project that was created fully within Unreal Engine 4 to be a horror level design project. This project had its very own game design document to go with it.

• Portals - Portals was created within this project as a new way of transportation. This was the first time I had ever attempted creating anything with a portal. It included the use of a camera to show off what the other side could see, giving off the effect of it being bigger on the inside / being able to see through it to a different area just like how it is done in the Portal games created by valve.

• Checkpoints - Allowed me to save the players progress so that if anything was to occur during the game their progress would restart from that point upon revival

• Level Streaming - Allowed me to switch out assets and change the entire style of the game at runtime. However as this was the first time that I had ever used level streaming I found out that loading in too much stuff at once can cause a very large FPS drop.
