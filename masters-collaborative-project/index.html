The Demon Character Viewer and Asset Pack

The demon character viewer and asset pack project was created by a total of 5. The project had 3 3D character designers and 2 technical developers, it was created thoughout the course of 12 weeks. During the creation of this project, I set myself the tasks of designing features that would be used throughout the project as a technical designer. These features include:

• Ray tracing with saveable values that can be stored in a save file and relaunched / modified at any time.

• Created a functional main menu and pause menu system with inegrated ray tracing settings.

• Created a level for the characters to be able to be placed upon while in the viewer itself.

• Created a game design treatment document that acts as a base of what type of stuff to expect to be within the project, including controls and who will be designing each section.
