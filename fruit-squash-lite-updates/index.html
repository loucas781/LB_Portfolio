Fruit Squash Lite Version History

  • iOS
  • Android

1.0.14
• Updated credits
• Updated support for iOS 18
• Updated minimum version support to iOS 15
• Updated minimum version support to MacOS 13 with Apple Silicon
• Added in a darker app icon when using dark icons on iOS 18
• Enabled support for iPad split screen while playing
• Re-added Game Centre support (Leaderboards)

1.0.13
• Updated app icon
• Added in support for online only play*
The game can now only be played while having an active network connection via either Wi-Fi or 4G/5G

1.0.12
• Removed Christmas effects*
Snowflakes falling across screen
Christmas backgrounds
Christmas Font
Christmas background music
• Removed all Christmas related items from game package

1.0.11
• Updated how game save is deleted
• Added a screen informing the player the save is being deleted when the button is pressed
• Increased all animation speeds*
Speeds increased to 0.35 seconds from 0.50
• Updated text in the settings menu to display more information for some toggles
• Removed Default backgrounds & Music from the package
• Added Christmas effects to the game
• Added Christmas Music to the game
• Updated game font to a Christmas font
• Updated backgrounds for Christmas

1.0.10
• Removed Halloween content from the game
• Removed Halloween event backgrounds and sounds from the game package
• Updated game font back to default
• Added in default background music
• Reduced file size of background music by compressing the audio more to reduce app size

1.0.9
• Reduced app size
• Enabled 120hz on compatible devices
• Background music should now loop after finishing and restart rather than cutting out
• Removed unused event background and sounds from package
• Added more padding between stats values in settings
• Interstitial ads should now pause background music and unpause when closed

1.0.8
• Fixed a save game issue, where on a fresh install the game would not save correctly till on the second load, causing data loss
• Added support for large numbers turning into smaller numbers*
1,000 will now turn into 1K
1,000,000 will now turn into 1M etc
• Added option to toggle background music on or off in settings
• Added support for background music*
3 songs currently in a halloween theme

1.0.7
• Updated game font to a Halloween font
• Added Spiderweb to the top UI
• Wallpapers updated to Halloween background images

1.0.6
• Added support for iOS 17
• Moved the "BACK" and "SPIN" button locations to be in the same position as the "SETTINGS" button
• Increased size of Theme Store, Fruit Store, Settings, and WOFs
• Updated background images*
Five new backgrounds to replace the old three
• Updated WOF font to match game font
• Updated WOF image and text locations to be more centered
• Updated credits starting point for large screen sizes
• Temporarily disabled Game Center support

1.0.5
• Added a second WOF that appears after 500 auto cookers have been purchased
• Increased padding between UI buttons for easier scrolling
• Changed how UI buttons press for easier scrolling
• Added support for random background images*
3 background images will now appear in game at random on each load
• Added Banana Theme 

1.0.4
• Updated ads plugin
• Disabled engine plugins
• Added interstitial ads
• Added mobile battery symbol to top left UI

1.0.3
• Added support for mediation
• Added GDPR consent form
• Added GDPR button in settings to toggle GDPR consent form
• Added support for ATT
• Shifted UI up to accommodate new ad location

1.0.2
• Updated Game Engine
• Added in support for WOF to appear after game restart if previously active
• Moved SETTINGS button up slightly
• Updated WOF to trigger when greater than instead of equal too

• Fixed issues with leaderboards
